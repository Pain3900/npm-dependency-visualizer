# Конфигурационное управление. Вариант №15

CLI для анализа зависимостей пакетов npm. Для запуска нужен Python 3.10+.
Сборка и установка Python-библиотек не требуются.

```sh
./run.sh --package is-odd --repo https://registry.npmjs.org
python3 -m unittest discover -v
```

| Опция | Назначение |
| --- | --- |
| `--package` | Имя npm-пакета, в том числе `@scope/name`, или имя локальной вершины |
| `--repo` | URL реестра npm или путь к локальному JSON |
| `--test` | Читать тестовый репозиторий из JSON |
| `--ascii` | Печатать ASCII-дерево |
| `--filter TEXT` | Исключать имена, содержащие заданную подстроку |

На первом этапе CLI печатает параметры в формате `ключ=значение`.
Флаги `--test` и `--ascii` задаются без значения.
